# Fortbildungsergebnisse dokumentieren

1. Die vermittelte Aufgabe und den zuständigen Fachartikel bestimmen.
2. Voraussetzungen, Versionen, Ausgangsdaten, Arbeitsschritte und erwartetes Ergebnis ergänzen.
3. Den Ablauf durch eine zweite Person erproben lassen.
4. Änderungen als Pull Request gegen dev einreichen beziehungsweise mit der Redaktion der zuständigen Programmdokumentation abstimmen.
5. Vom Veranstaltungseintrag auf den fertigen Fachartikel verlinken.

Eine noch ausstehende Ausarbeitung wird im [redaktionellen Arbeitsstand](./inhaltsstand.md) festgehalten. Für Schulungsaufgaben gilt [Material pflegen](/moderation/material-pflegen).
