# Frühere FBM-Werkzeuge

Diese Skripte stammen aus dem FBM-Import. Die Dokumentationsprüfung und die Veröffentlichung verwenden sie nicht. Der frühere SQLite-Mehrfachimport sucht seine lokale .env und Quelldateiliste im Verzeichnis des Skripts. Für neue Schulungsinstallationen sind die Anleitungen unter Datenbanken & Installation maßgeblich.
